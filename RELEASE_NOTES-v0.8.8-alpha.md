# Hearthroot Control v0.8.8-alpha

First unified alpha release of Hearthroot Control and Hearthroot Companion.

## Features

- CPU and I/O profiles for Hearthroot Kernel.
- Native, Balanced, Battery Saver and Performance profiles.
- Optional LSPosed Companion integration for Xiaomi Parts.
- Profile synchronization and boot-state restoration.
- Integrated WebUI and seasonal themes.
- Optional Companion installation through the module installer.

## Improvements

- Restored profile state after reboot.
- Improved Android SDK build compatibility.
- Persistent Companion APK signing in GitHub Actions.
- Automated module packaging and release verification.

## Notes

- Alpha release intended for testing.
- Requires a compatible Hearthroot Kernel for full functionality.
- Xiaomi Parts integration requires the optional Companion and LSPosed configuration.
