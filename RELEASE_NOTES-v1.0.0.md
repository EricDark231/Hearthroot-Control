# Hearthroot Control v1.0.0

The first official stable release of Hearthroot Control.

Hearthroot Control provides a unified WebUI for managing Hearthroot Kernel profiles, with optional Xiaomi Parts integration through Hearthroot Companion.

## Features

- Native, Balanced, Battery Saver and Performance profiles.
- Experimental profile with advanced controls.
- CPU governor and I/O scheduler management.
- Optional Xiaomi Parts synchronization.
- Hearthroot Companion integration through LSPosed.
- Automatic restoration of supported profile settings after reboot.
- Integrated profile application and recovery mechanisms.
- Real-time application progress feedback.
- Diagnostics and profile status information.
- Nine seasonal WebUI themes.

## Safety and recovery

- Recovery of previously saved kernel settings.
- Recovery handling for partial application failures.
- Xiaomi Parts mode restoration when available.
- Automated regression tests for recovery behavior.
- No direct thermal-disabling controls.
- Xiaomi Parts Extreme mode intentionally excluded.

## Compatibility

- Designed for Hearthroot Kernel on POCO X7 Pro (rodin).
- Requires root access through a compatible module manager.
- Xiaomi Parts integration requires Hearthroot Companion and LSPosed.
- Companion integration is optional.

## Included components

- Hearthroot Control v1.0.0
- Hearthroot Companion v0.3.8-alpha

## Installation

1. Download the release ZIP.
2. Install it using a compatible root module manager.
3. Reboot the device.
4. Open Hearthroot Control from the module manager.
5. Configure optional Companion integration if required.

## Notes

This is the first official v1.0.0 release. Advanced and Experimental settings should be used carefully.

Companion APK signing is verified during the release workflow.
